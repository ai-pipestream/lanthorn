# tui/app — TUI & Orchestration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable terminal program, `lanthorn <story-file>`, that runs a Z-machine game in a split TUI (transcript + live automap), bridges each turn from the VM's current location into the mapper, supports scroll/zoom and modal map-editing, persists the map per-IFID and game saves as Quetzal files, and exports the map to SVG.

**Architecture:** A new binary crate `app` (binary name `lanthorn`) that depends on `zvm`, `mapper`, `ratatui`, and `crossterm`. It is the integration layer (spec §2): per turn it drives the VM (`zvm`), captures transcript output, reads `zvm::current_location`, and calls `mapper::observe`. Pure logic (IFID, persistence, the turn driver, state transitions, the map→screen projection, input→action mapping, SVG generation) lives in testable modules; the `main.rs` run loop is thin glue over them. Rendering is tested via ratatui's `TestBackend` (in-memory buffer).

**Tech Stack:** Rust (stable, edition 2021), the existing Cargo workspace. New deps (app crate only): `ratatui = "0.29"`, `crossterm = "0.28"`. `zvm` and `mapper` are workspace path deps. SVG is hand-generated (no rasterizer dep — PNG is a deliberate follow-up).

## Global Constraints

- **`app` is the only crate doing terminal I/O and game-state/map file I/O.** `zvm` stays filesystem-free; `mapper` stays VM-agnostic and filesystem-free. The app bridges them. (spec §2, §5)
- **Per-turn bridge (spec §2 data flow):** user submits a line → app records whether `parse_direction(line)` is a movement → `zvm` runs the turn, app captures screen output → app reads `zvm::current_location(&machine)` → `mapper.observe(location.number, &location.name, dir)` → re-render. The destination room is always observed (rooms never lost).
- **IFID keying:** the per-game map file is keyed by the story's IFID. For Z-code, IFID = `ZCODE-<release>-<serial>-<checksum-hex>` computed from header bytes (release @0x02 BE u16; serial @0x12..0x18 6 ASCII bytes; checksum @0x1C BE u16). (spec §5; Treaty of Babel)
- **Map persistence:** single cumulative map per IFID; auto-load on start, auto-save on clean exit (and on explicit save). Quetzal game saves are SEPARATE `.qzl` files (portable), never bundled with the map. (spec §5)
- **TUI behavior (spec §6):** default split view (transcript + map); map collapsible to full-screen transcript and expandable to full-screen map; current room highlighted ("you are here"); pan with arrows AND `hjkl`, zoom with `+`/`-`, a key recenters on current room; discrete zoom levels (full box / abbreviated / glyph). Zoom/scroll are view state, NOT persisted.
- **Editing is modal (decided):** `Tab` toggles focus between Game and Map panes. In **Map focus**, game input is paused; arrows/`hjkl` pan, `+`/`-` zoom, `Tab`/`Esc` return to Game. Map-edit ops act on the selected room/edge via single keys (see Task 8). Light corrections only: rename room, edit notes, nudge (Manual mode), delete connection, relabel an Unknown edge. (spec §5)
- **Export:** SVG only in v1 (vector). PNG is out of scope (follow-up). (decided; spec §7)
- **No panics leaving a broken terminal:** the run loop installs terminal raw-mode setup/teardown and a panic hook that restores the terminal. (production-readiness)
- **TDD:** failing test first, run to see fail, implement, see pass. Commit per green task. `cargo test -p app` (cargo on PATH). Rendering tests use `ratatui::backend::TestBackend`.

### Task 8: Input → `Action` mapping + apply

**Files:**

**Interfaces:**
- Consumes: `crossterm::event::{KeyCode, KeyModifiers, KeyEvent}`, `AppState`, `Focus`, `mapper::Mapper`, `mapper::direction::Direction`.
- Produces:
  - `pub enum Action { SubmitCommand(String), InputChar(char), Backspace, ToggleFocus, CycleLayout, ZoomIn, ZoomOut, Pan(i32,i32), Recenter, SelectNext, SelectPrev, RenameRoom, EditNotes, DeleteSelectedConnection, RelabelSelectedEdge, NudgeSelected(i32,i32), SaveGame, RestoreGame, ExportSvg, Quit, None }`
  - `pub fn key_to_action(state: &AppState, key: KeyEvent) -> Action` — routing:
    - Global (any focus): `Ctrl+Q` or `Ctrl+C` → Quit; `Ctrl+S` → SaveGame; `Ctrl+R` → RestoreGame; `Ctrl+E` → ExportSvg; `Ctrl+L` → CycleLayout; `Tab` → ToggleFocus.
    - **Game focus:** printable char → InputChar; `Backspace` → Backspace; `Enter` → SubmitCommand(state.input clone).
    - **Map focus:** `Left/h`→Pan(-1,0), `Right/l`→Pan(1,0), `Up/k`→Pan(0,-1), `Down/j`→Pan(0,1); `+`/`=`→ZoomIn, `-`→ZoomOut; `c`→Recenter; `n` (next) / `N` (prev) → SelectNext/SelectPrev; `r`→RenameRoom; `o`→EditNotes (mnemonic: nOtes; `n` is taken by select-next); `d`→DeleteSelectedConnection; `e`→RelabelSelectedEdge; `Shift+arrows`→NudgeSelected; `Esc`→ToggleFocus.
