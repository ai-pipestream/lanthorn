**Goal:** Replace gvm's `Output` placeholder with a real Glk window/stream/output model + a `GlkBackend` display trait, implement the output-side `@glk` subset, and give `gvm-cli` a terminal output backend (status grid + scrolling buffer). Input/events + glulxercise are 3a-2.

**Spec:** `docs/superpowers/specs/2026-06-27-glk-io-design.md`

## Existing interfaces

- `crates/gvm/src/io.rs`: `Output` trait + `BufferOutput` (the 2a placeholder — being replaced).
- `crates/gvm/src/exec.rs`: `Machine { out: Box<dyn Output>, iosys_mode, … }`, `with_output(mem, Box<dyn Output>)`, `op_glk` → `glk_dispatch(selector, args)` (currently prints to `self.out`), `op_streamchar`/`streamnum`/`streamstr` (emit under iosys 2). **93 existing tests** use `BufferOutput` and assert printed text.
- `crates/gvm/src/asm.rs` (`#[cfg(test)]`): program builder.
- `crates/gvm/GLULX_NOTES.md`: extend with a Glk section (transcribe from the **Glk spec**, Andrew Plotkin — WebFetch it).

## CRITICAL: keep all existing tests green

The 93 gvm tests print via `glk_put_char`/`streamnum` to `BufferOutput`. After
the refactor, output goes to the **current Glk stream → a window**. Preserve
coverage by migrating, not deleting:
- Add a `#[cfg(test)]` **prelude** to the asm helper that opens a TextBuffer
  window and sets it current (so test programs have somewhere to print).
- `TestBackend` accumulates the TextBuffer window's text into a `String` the
  tests read (replacing `BufferOutput::buf`).
- Mechanically update existing tests to use the prelude + `TestBackend`; the
  asserted strings stay the same. **No test may be deleted or weakened.**
